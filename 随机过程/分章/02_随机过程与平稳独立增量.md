# 第02章 随机过程、数字特征、平稳性与独立增量

来源：C1 p43–81，C2 p1–11。课件要求：理解随机过程及其分类、有限维分布；熟练掌握数字特征；掌握严/宽平稳定义、独立增量定义及判断方法。

## 2.1 随机过程是“一族随机变量”

【课件 C1 p44–49】在同一个概率空间上，对每个参数 $t\in T$ 都有一个随机变量 $X(t)$，于是

$$\{X(t),t\in T\},\qquad X(t)=X(t,\omega)$$

构成随机过程。参数一般表示时间，但也可以表示位置。$T$ 是参数集；过程所有可能状态构成状态空间 $S$。

理解它的两个切面：

- 固定 $t=t_0$，让 $\omega$ 变化：$X(t_0,\omega)$ 是一个随机变量。它描述“同一时刻不同可能结果”。
- 固定一次试验 $\omega=\omega_0$，让 $t$ 变化：$x(t)=X(t,\omega_0)$ 是一条确定的样本函数/样本路径。它描述“一次实现随时间的变化”。

两者都固定时，$X(t_0,\omega_0)$ 只是一个数。不能把单条观测曲线直接等同于整个随机过程。

课件的到港船舶例子：$N(t)$ 记录从0到$t$到港的船数。某一天实际记录的阶梯曲线是一条样本路径；固定下午某时刻，船数仍有不同可能，是随机变量。

## 2.2 参数、状态与课件中的模型例子

【课件 C1 p50–62】

|参数集 $T$|状态空间 $S$|课件范围的例子|
|---|---|---|
|离散|离散|每次掷骰子点数、整数位置的随机游动|
|离散|连续|按离散时刻记录的实值序列|
|连续|离散|到达人数、等待队长|
|连续|连续|噪声波形、顾客等待时间过程|

时间为离散点时称随机序列；参数为高维向量时课件称随机场，仅理解术语，不扩展随机场计算。

**原课件例子：**

1. 随机游动：每一步以概率 $p$ 向右1、概率 $1-p$ 向左1，记录位置。
2. Brown运动：微粒随机运动作为背景模型；当前材料未给它的系统定义和计算要求，不开展独立专章。
3. 排队模型：$X(t)$ 为等待队长，$Y(t)$ 为时刻$t$到来的顾客所需等待时间，$Z(t)$ 为 $[0,t]$ 内到达人数。$X,Z$ 状态离散，$Y$ 状态连续。
4. 信号流：不同接收机的噪声波形体现“同一时刻随机变量/一次实现曲线”的区别。
5. 圆木截面积：选定一根圆木后，沿长度位置的截面积曲线是一条样本函数；固定位置考察随机选择的圆木，则得到随机变量。
6. 掷骰子：$X(n)$ 为第$n$次点数，$Y(n)=\sum_{k=1}^nX(k)$ 为累计点数。原始数值序列和累计过程不是同一个过程。

课件选择题对应：固定时刻的 $N(t)$ 是随机变量；商场累计客流可用连续时间、离散状态过程描述；队长和等待时间分别为离散状态、连续状态。

## 2.3 有限维分布：既描述单时刻，也描述跨时刻关系

【课件 C1 p63–69】一维分布为 $F_t(x)=P\{X(t)\le x\}$；二维分布为

$$F_{t_1,t_2}(x_1,x_2)=P\{X(t_1)\le x_1,X(t_2)\le x_2\}.$$

一般地，

$$F_{t_1,\ldots,t_n}(x_1,\ldots,x_n)=P\{X(t_1)\le x_1,\ldots,X(t_n)\le x_n\}.$$

把所有有限个时刻的联合分布收集起来，得到有限维分布族。只知道每个时刻各自的边缘分布，通常不知道时刻之间的依赖；所以不能只用一维分布代替整个分布族。

两个性质：

1. **对称性：** 同时重排时刻和对应阈值，概率不变，因为事件的交不因书写次序变化。
2. **相容性：** 把某些坐标阈值送到 $+\infty$，就得到剩余坐标的分布。

课件的Kolmogorov相容性定理：若一族真正的有限维分布满足上述对称性和相容性，就存在一个随机过程以它们为有限维分布。本课记住定理的作用和条件，不展开测度论证明或额外样本路径定理。“完整描述”在这里指过程的有限维概率规律，不额外推断每条路径具有连续性等性质。

## 2.4 均值、协方差、自相关与方差函数

【课件 C1 p70–73】在相应期望存在时，

$$\mu_X(t)=E[X(t)],$$
$$R_X(s,t)=\operatorname{Cov}(X(s),X(t))=E[(X(s)-\mu_X(s))(X(t)-\mu_X(t))],$$
$$r_X(s,t)=E[X(s)X(t)],$$
$$R_X(s,t)=r_X(s,t)-\mu_X(s)\mu_X(t),\qquad D[X(t)]=R_X(t,t).$$

若每个时刻的 $E[X^2(t)]$ 均有限，称为二阶矩过程。这里的 $R$ 是协方差，不是自相关；接续AI必须保持这一约定。

**原课件例1.1.7（C1 p72）：** $X(t)=X_0+tV$，其中 $X_0,V$ 独立且都服从 $N(0,1)$。

先计算 $E[X(t)]=0$。再展开

$$E[X(s)X(t)]=E[X_0^2]+(s+t)E(X_0V)+stE(V^2)=1+st.$$

由于均值为0，$R_X(s,t)=1+st$，$D[X(t)]=1+t^2$。协方差依赖具体的 $s,t$，方差也随时刻变化，因此这个过程不是宽平稳过程。

**原课件选择题（C1 p71）：** $Y(t)=5\sin(\pi t+X)$，$P(X=0)=0.2$、$P(X=\pi/2)=0.8$。

$$E[Y(2)]=5[0.2\sin(2\pi)+0.8\sin(2\pi+\pi/2)]=4.$$

注意该题在C1原图的条件是 $X=0.5\pi$，不能误抄成 $X=1.5\pi$。这里 $\sin(5\pi/2)=1$。

## 2.5 严平稳与宽平稳

【课件 C1 p74–81，C2 p1】

**严平稳：** 对任意有限个时刻和任意允许的平移 $h$，

$$\bigl(X(t_1+h),\ldots,X(t_n+h)\bigr)\overset d=\bigl(X(t_1),\ldots,X(t_n)\bigr).$$

这里是不改变**联合分布**，不是两组随机变量逐点相等，也不是每条曲线水平不动。严平稳过程的一维分布不随时刻变，二维分布只与时间差有关。

**宽平稳/二阶矩平稳：** 三个条件缺一不可：

1. 各时刻二阶矩有限。
2. $E[X(t)]=\mu$ 为常数。
3. 协方差只依赖时间差：$R_X(s,t)=R_X(t-s)$。

于是 $D[X(t)]=R_X(0)$ 为常数。也可用“均值常数、自相关只依赖时差”判断，因为 $R_X(\tau)=r_X(\tau)-\mu^2$。

课件列出的协方差性质：$R_X(\tau)=R_X(-\tau)$，即偶函数；$R_X(0)=D[X(t)]$；对实数 $a_i$，

$$\sum_i\sum_j a_i a_jR_X(t_i-t_j)\ge0.$$

最后一式的含义是某个线性组合的方差不可能为负，不必把它扩展成另一个分析专题。

**关系：** 严平稳且有有限二阶矩，才推出宽平稳。严平稳本身不保证二阶矩存在；宽平稳只管前两阶矩，通常不能推出严平稳。原课件两道“一定是吗”的选择题都应选“不一定”。

### 判断宽平稳的固定步骤

先求均值；若不是常数立即否定。再确认二阶矩有限；最后求 $R_X(s,t)$ 并化简，看是否只剩 $t-s$。不能只检查均值，也不能只检查方差。

## 2.6 平稳白噪声与滑动平均序列

【课件 C2 p2–8】课件“平稳白噪声序列”的条件为两两不相关、均值0、共同方差 $\sigma^2$：

$$E(X_nX_m)=\begin{cases}\sigma^2,&n=m,\\0,&n\ne m.\end{cases}$$

因此协方差只取决于是否同一时刻，是宽平稳序列。**课件这里用的是不相关，不可偷偷升级为相互独立。**

滑动平均例：$\{\varepsilon_n\}$ 两两不相关，均值 $\mu$、方差 $\sigma^2$ 相同，固定系数 $a_1,\ldots,a_k$，

$$X_n=\sum_{j=1}^{k}a_j\varepsilon_{n-j+1}.$$

由期望线性性，$E(X_n)=\mu\sum_{j=1}^ka_j$，与 $n$ 无关。

令 $\tau\ge0$，比较两个和中的 $\varepsilon$ 下标；不同下标协方差为0，只有重合项留下：

$$R_X(\tau)=\begin{cases}\sigma^2\sum_{j=1}^{k-\tau}a_ja_{j+\tau},&0\le\tau<k,\\0,&\tau\ge k.\end{cases}$$

负的 $\tau$ 由偶对称性得到。协方差只取决于间隔，因此宽平稳。

**应会复现的推导思路：** 展开双重求和 → 用不相关性去掉不同下标 → 统计重叠长度 $k-|\tau|$ → 得到仅依赖时差的式子。不要把这个例子扩展为ARMA模型课程。

## 2.7 独立增量与平稳独立增量

【课件 C2 p9–11】增量是两个时刻的差 $X(t_2)-X(t_1)$。

若对任意 $t_1<\cdots<t_n$，相邻不重叠区间上的增量

$$X(t_2)-X(t_1),\ X(t_3)-X(t_2),\ \ldots,\ X(t_n)-X(t_{n-1})$$

相互独立，就称独立增量过程。若等长区间的增量还有相同分布，即

$$X(t+h)-X(t)\overset d=X(s+h)-X(s),$$

则为平稳独立增量过程。

**最重要的区分：** 平稳增量说的是“差值的分布”不随起点变化；平稳过程说的是“过程自身的分布/矩”不随平移变化。前者不推出后者。第04章Poisson过程的 $E[N(t)]=\lambda t$ 就会提供直接例证。

**原课件选择题（C2 p10）：** 若 $X(0)=0$ 且具有独立增量，以下哪些一定独立？

- $X(1)-X(0)$ 与 $X(2)-X(1)$：是，不重叠区间。
- $X(1)$ 与 $X(3)-X(1)$：是，$X(1)$ 等于 $X(1)-X(0)$。
- $X(2)-X(1)$ 与 $X(3)-X(1)$：不能保证，区间重叠。
- $X(1)-X(2)$ 与 $X(3)-X(2)$：是，第一个仅是区间 $(1,2]$ 上增量的相反数。

原题应选A、B、D。

独立和例：$Z_i$ 独立同分布，$X_n=\sum_{i=0}^nZ_i$。不同不重叠区间的增量是不同组 $Z_i$ 的和，因而独立；等长整数区间包含相同个数的同分布项，增量分布相同。注意原式 $X_0=Z_0$，不必等于0。

## 2.8 本章掌握检查

1. 解释固定$t$与固定$\omega$后各得到什么。
2. 对 $X(t)=X_0+tV$ 独立标准正态例，独立算出均值、协方差、方差并判断宽平稳。
3. 口述严平稳与宽平稳的区别，说明附加哪个条件时严平稳推出宽平稳。
4. 对滑动平均例独立找出协方差中保留下来的重叠项。
5. 用区间图判断哪些增量独立，而不是只看公式里的字母。

**同范围检查：** 若 $X_n=2\varepsilon_n+\varepsilon_{n-1}$，$\varepsilon_n$ 两两不相关、均值0、方差1，求均值和协方差。

教师答案：均值0，$R(0)=5$，$R(1)=R(-1)=2$，$|\tau|\ge2$ 时为0，所以宽平稳。除非另有分布条件，不能仅凭这些断言严平稳。
